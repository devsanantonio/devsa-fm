The code in this repo is MIT licensed (see `LICENSE`). The artwork below is not: it is DEVSA's
brand, © DEVSA, all rights reserved.

**You may** use these files in DEVSA FM scenes, in this repo or a fork of it, while you build and
propose a scene.

**You may not** use them anywhere else (other projects, merch, your own channel or social posts
presented as yours) without DEVSA's written permission. Ask at devsa.community.

| Files | What they are |
|---|---|
| `scene/devsa-logo.svg`, `scene/devsa-alt-logo.svg`, `mark/`, `thumbnail/devsa-logo.svg` | the DEVSA mark and the DEVSA FM mark |
| `scene/sticker-*.png`, `scene/devsa-window-sticker.png` | DEVSA's stickers |
| `scene/penguin.png` | the pixel penguin DEVSA drew for Linux San Antonio |
| `scene/pysa-mascot-full.webp` | the PySanAntonio mascot |
| `scene/alamo-python-dark.png` | the Alamo Python mark, designed by DEVSA |
| `scene/proj/mhth/`, `scene/proj/pysa/`, `scene/proj/ag/` | frames from DEVSA's conference films: More Human Than Human, PySanAntonio, Access Granted |
| `social/`, `thumbnail/` (images) | DEVSA FM's social graphics and stream thumbnails |

When you use the mark, keep it as it is: no wordmark set beside it, never inverted or recoloured.

## Not in the repo

These are used on the stream but aren't published here, so a fresh clone runs without them:

- **The City of San Antonio's line icons** (`scene/icons/`). Scenes draw them if they're present
  and skip them if not.
- **Other organizations' logos** (`scene/proj/groups/`, `scene/proj/partners/`).
- **The music** (`music/`, `music-tejano/`). Each folder's `credits.txt` is here; the tracks aren't.
